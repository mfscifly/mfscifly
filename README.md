# Hey, I'm Daniel 👋

I build with Claude Code, and I use it to change how companies work.

By day I lead AI at [Clearbridge Business Solutions](https://clearbridge.ca), a Claude Partner. The model is rarely the hard part. The hard part is finding where the work actually happens, building something that takes the friction out, and getting people to trust it enough to use it. Our dev team doesn't write code by hand anymore, and agents now handle a good share of our tickets and documentation.

### How I think about it

- **Start from the work, not the tool.** Sit with the people doing the job before building anything.
- **Adoption is the product.** A tool nobody uses saves nothing.
- **Build the checks in.** Agents get reviews and scores, and a person stays in the loop where judgment matters.
- **Show the wins every week.** Momentum spreads team to team faster than any mandate.
